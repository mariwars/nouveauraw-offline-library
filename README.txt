NouveauRaw / Amie Sue — личная локальная библиотека
Источник: https://nouveauraw.com/
Дата сохранения: 10 сентября 2026

КАК ОТКРЫТЬ
Откройте START_HERE.html двойным щелчком. В каталоге есть поиск по
английским названиям и переключатель «Только рецепты».
Для печати открытого рецепта нажмите Ctrl+P в браузере.
Во время загрузки каталог может быть неполным; он обновится в конце.
Рецепты и фотографии принадлежат Amie Sue; авторство сохранено.

ПАПКИ
pages — страницы для чтения без интернета.
assets — сохранённые фотографии и PDF.
texts — текстовые копии страниц в UTF-8.
originals — исходный HTML сайта, включая комментарии, если они были на странице.
sources — карты сайта, по которым собирался архив.
report.json — итоговые количества и список неудавшихся загрузок.
pages_manifest.json / assets_manifest.json — адреса и соответствующие файлы.

ОГРАНИЧЕНИЯ
Это библиотека для чтения, с упрощённым оформлением.
Отправка комментариев, избранное исходного сайта, пожертвования и другие
серверные функции не работают локально. Внешние видеоролики и внешние
сайты не скачиваются. Тексты не переводились.
Количество рецептов определяется автоматически по наличию ингредиентов
и инструкций; некоторые рецепты могут находиться только в общем списке.

ПРОДОЛЖИТЬ ЗАГРУЗКУ
Если нужно перенести архив, скопируйте всю эту папку на другой диск.
На этом компьютере requests, beautifulsoup4 и lxml уже установлены.
Из PowerShell в папке архива:
    python archive_site.py
Скрипт использует уже скачанные файлы и повторяет неудавшиеся загрузки.
Фотографии перестают загружаться при остатке менее 550 МБ свободного места.
Завершение обозначается строкой DONE в журнале загрузки.
