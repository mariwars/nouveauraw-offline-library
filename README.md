# NouveauRaw — личная библиотека рецептов

Приватный архив сайта [NouveauRaw / Amie Sue](https://nouveauraw.com/), сохранённый 10 сентября 2026 года. Репозиторий предназначен для переноса личной копии между компьютерами.

После скачивания откройте **START_HERE.html** в браузере двойным щелчком. Интернет, Python и сервер для чтения не нужны. На самом GitHub HTML показывается как исходный код — библиотеку нужно сначала скачать.

В каталоге 2 066 уникальных страниц. Сохранены все 1 867 статей из карты сайта, 8 798 изображений и 17 PDF. Фильтр автоматически распознаёт 1 454 страницы с ингредиентами и инструкциями. Есть поиск по английским названиям.

Все файлы библиотеки находятся непосредственно в Git. Git LFS и отдельная загрузка фотографий не нужны. Размер самих файлов — около 1,5 ГБ; для клонирования с историей Git подготовьте не менее 4 ГБ свободного места.

## Скачать на другой компьютер

Полная пошаговая инструкция, включая доступ со второго аккаунта: **[TRANSFER.md](TRANSFER.md)**.

Если Git и GitHub CLI уже установлены, откройте PowerShell в папке, куда хотите скачать библиотеку:

```powershell
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git --hostname github.com
gh repo clone mariwars/nouveauraw-offline-library nouveauraw-offline-library -- --depth 1
Set-Location -LiteralPath .\nouveauraw-offline-library
Invoke-Item -LiteralPath .\START_HERE.html
```

Войдите под `mariwars` или под аккаунтом, которому уже выдан доступ и который принял приглашение. Если нужный аккаунт уже авторизован, повторный вход не требуется.

Без Git: войдите в GitHub, откройте репозиторий, выберите **Code → Download ZIP**, распакуйте архив целиком и откройте `START_HERE.html`.

## Скрипты

Для обычного чтения их запускать не нужно. Повторный запуск загрузчика обращается к исходному сайту и может обновить библиотеку.

```powershell
python -m pip install -r requirements.txt
python verify_archive.py
```

`archive_site.py` — продолжение загрузки; `fast_reader.py` — пересборка страниц; `finalize_archive.py` — проверка и обновление итогового отчёта.
